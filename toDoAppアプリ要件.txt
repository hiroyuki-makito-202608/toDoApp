ToDo管理アプリを作成してください。

■目的
日常のtoDoを管理したい。
WebのローカルアプリWebでtoDoを管理したい。


■toDoアプリの機能要件
〇管理するデータ種別
・ID（自動で振られる）
・完了フラグ（完了したときにチェックが入る）
・タスクのカテゴリ（雑務、学習、求職）から選択、フリーで入力することも可能
・タスクの内容
・詳細/どう実現するか
・優先度（高・中・低　のいずれかから選択できる。デフォルトは中）
・重要度（高・中・低のいずれかから選択できる。デフォルトは中）
・期限日　（デフォルトは入力した日＋７日後。カレンダーで入力することも可能）
・入力日（自動で入力した日が入る）
・完了日　（デフォルトは入力した日。カレンダーで入力することも可能）

〇ユーザーのアクション
・データ入力：常にデータ入力フィールドがページの先頭に表示され入力できるようになっている。
・一覧表示：タスクのステータスを表形式で表示
・エディット：タスクのカテゴリを再度選択/編集、タスクの内容の編集、詳細/実現方法の編集、優先度を再度選択、重要度を再度選択、期限日の編集、完了日の編集、完了on/off　

・未完了だけ表示/非表示する機能。トグルボタン
・タスクの削除

〇画面
・1ページで実現
・新規タスクを登録できるフィールドが画面上方にならぶ
・その下に、管理しているtoDoの表が表示される。
・最後の行は空行になっている。
・表の1行を選択すると、既存のタスクを編集できる
・最後の行を選択すると、新規タスク追加
・IDはユニークでいままで振った番号より1大きいものがふられる。
・タスクのカテゴリは、過去入力したものをDBに記録しておき、リストに表示、選択できる。新規にカテゴリの内容を登録することもできる。
・画面の並び
　タイトル：ToDoApp  
　入力フィールド
　タスクリスト（表）
・ページ全体の色調：パステル調の水色をベースのカラー
・表の色調：見やすく１行づつ交互に色を変えてください（同じ系統の色、薄緑系）


■実現方法
・Javaで実装
・Webアプリケーションとして作成。HttpServerはJava標準のクラスを使用（com.sun.net.httpserver.HttpServer）
・コマンドラインでtoDoAppserverを起動し、ブラウザでlocalhosot:8081を参照することによって実行
・フレームワークは利用しない。
・データの永続的保存にSQLiteを利用する

■実装条件詳細
・com.sun.net.httpserver.HttpServer を使う（フレームワークや外部ライブラリは使わない）
・起動すると待ち受け状態になり、ブラウザで http://localhost:8080/ を開くと「Hello, Server!」と表示される
・起動したら、ターミナルに「サーバー起動: http://localhost:8080 （止めるときは Ctrl+C）」とそのまま表示してください（英語にせず、この日本語のまま）
・返す文字を日本語に変えても文字化けしない（UTF-8で返す）
・"/" に来たときの処理は、server.createContext("/", exchange -> { ... }) の形で、createContext の2つ目の引数に直接書いてください（別のメソッドやクラスに分けないでください）
・返す文字は、message という名前の変数に入れてください
・サーバーは HttpServer server = HttpServer.create(new InetSocketAddress(8080), 0); の1行で用意してください
・返す文字の行は、"/" に来たときの処理の { } の中に、String message = "Hello, Server!"; の形で書いてください
・message の行のすぐあとに、exchange.getResponseHeaders().set("Content-Type", "text/plain; charset=UTF-8"); の1行を書いてください
・その次に、文字を送り返す部分を byte[] body = message.getBytes("UTF-8"); → exchange.sendResponseHeaders(200, body.length); → exchange.getResponseBody().write(body); → exchange.getResponseBody().close(); の4行で、この順に書いてください
・main は public static void main(String[] args) throws Exception { の形にしてください
・public classの名前は"ToDoApp"とする
・基本のHTML+Javaを実装後、後でスタイルシートでページのデザインを変えられるようタグを記載してください。
・タスクがないときは、表のすぐ上に「現在、タスクがありません」と１行表示する。

■合格条件（テスト項目）
・タスクを新規に登録、追加できること
・タスクを後から編集できること。
・サーバーを落としても、データは永続化されていること
・関係ないパスをURLに入力された場合は、そのパスはありません。とひとこと表示
・データ削除できること
